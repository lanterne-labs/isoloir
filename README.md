# isoloir

Anonymous polls with passport eligibility: prove once, with a passport,
that you may vote; vote anonymously, encrypted; let anyone recount from a
public log. No chain, no network of ours.

An isoloir is the voting booth: the curtain you vote behind, unseen.

The design and the plan: [PLAN.md](PLAN.md). The first instance is the
presidential pre-poll of tartuffe.me.
